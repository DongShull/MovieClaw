## movieclaw v0.27.0

**出门在外用 Infuse 看片，终于不转圈了。** 这一版让第三方播放器的「调低画质」
真正生效，手机网页换上了悬浮的液态玻璃底栏，一个文件夹里装着好几部电影的合集
也能一部不落地入库。

> ⚠️ **本版需要更新 Docker 镜像**：执行 `docker pull movieclaw/movieclaw:latest`
> 后重建容器即可。本版修正了一个会导致数据无法保存的底层组件问题，只有新镜像带着
> 这个修正，旧镜像会在「设置 → 更新与维护」里提示你升级。

### 本版亮点

#### 在外面用 Infuse 看片，调低画质真的有用了

以前在 Infuse、VidHub 里选低画质，服务端其实还在传原文件，手机流量或酒店 Wi-Fi
下看大片照样卡。现在客户端要多低的码率，movieclaw 就实时转成多低，字幕照常显示，
切换清晰度也干净利落。（需要有显卡，或在设置里开启了软件转码）

#### 手机网页换上液态玻璃底栏

银玻璃主题在手机上不用再点左上角 ☰ 找菜单了：发现、媒体库、订阅常驻在屏幕底部
一条悬浮的玻璃胶囊里，按住就能滑动切换，往下滚时自动收起、把画面让出来。发现页
也换成了沉浸式大图。

#### 一个文件夹装好几部电影？现在逐部入库

系列合集、打包下载的文件夹，以前只会收进最大的那一部、其余悄悄丢掉。现在每部都会
单独识别入库。升级后会自动把以前漏掉的补回来，不用你动手。

### 其他新功能

- **媒体库自定义封面**：给每个媒体库换一张喜欢的封面，Infuse 等客户端里也看得到。
- **飞书推送**：消息通知支持飞书群机器人，贴上 Webhook 地址就能用。

### 体验改进

- **Safari 播放 HEVC 的 MP4 起播更快**：iPhone、Mac 上不用再干等十几秒。
- **TMDB 镜像地址只填域名也能用**，不用再纠结后面要不要加路径。
- **「异常退出」提醒可以手动关掉**，不会一直挂在设置页。
- **Netflix 主题更统一**：各页面的边距、按钮和配色对齐了。

### 修复

- 在手机上给十几 GB 的大文件生成 AI 字幕不再失败，关掉对话框也会在后台继续完成。
- 「交给 Agent 处理」字幕时会带上你选的语言和双语设置。
- Windows 部署下图片显示不出来的问题已修复。
- 以及详情页背景闪烁、手机端若干显示问题等细节修复。

### 升级须知

- 本版升级了数据库。之后如需回退到 v0.26.0 或更早版本，请用更新前自动生成的备份
  恢复数据。
- 已知限制：Infuse 播放原盘时调低画质可能仍会失败；VidHub 尚未完整验证。
